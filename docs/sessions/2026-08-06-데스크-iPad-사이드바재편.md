# 2026-08-06 — 데스크 iPad 개선 1차: 사이드바 재편

## 배경

사용자가 데스크 앱을 iPad 가로모드로 주로 사용 — 이 전제로 개선 트랙 시작. 1차 대상은 좌측 사이드바(구 Workspace/Data/System)가 중구난방이라는 지적.

## 문제 진단

1. Workspace에 10개 중 6개가 몰려 섹션 구분이 무의미 + "내 자산"과 "시장"이 혼재
2. `Trade Log` 메뉴가 실제로는 ActivityPage(실현손익·세금 시뮬·매도 복기) — 이름·내용 불일치
3. Dividends는 placeholder("준비 중")만 렌더하는데 일반 메뉴처럼 노출
4. iPad 가로(1180px+)는 `lg` 데스크톱 레이아웃을 타는데 메뉴 행 `py-1.5`(~26px)로 터치 타깃 미달, 키보드 단축키 힌트가 터치에서 무의미

## 적용 (사용자 승인: 권고안 + Dividends 완전 제거)

- **4섹션 재편** — Portfolio(Dashboard·Today·Holdings·Analysis) / Activity / Market(Indicators·Price History) / System(KIS Status·Settings). 기준: "무엇에 대한 정보인가"
- **NavKey `tradelog` → `activity`** 개명 + 라벨 `Trade Log` → `Activity` (App SHORTCUTS·switch, MobileTabBar 탭 동기화)
- **`dividends` NavKey·메뉴·`v` 단축키 삭제** — 기능 자체는 로드맵 ⑤ 백로그에 유지(만들 때 메뉴 복원). App의 PlaceholderPage도 용도 소멸로 삭제
- **터치 타깃** — 메뉴 행 `py-2.5` 통일(~40px)
- **단축키 힌트** — tailwind 커스텀 variant `pointer-fine`/`pointer-coarse` 추가, 힌트는 `hidden lg:pointer-fine:inline`(마우스 환경에서만)

변경 파일: `web-desk/src/components/shell/Sidebar.tsx`·`MobileTabBar.tsx`·`App.tsx`·`tailwind.config.js` + `docs/code-map.md`

## 검증

- `tsc --noEmit` 0 에러, `npm run build` 성공, 빌드 CSS에 `@media (pointer:fine)` 생성 확인
- walk-through: iPad 가로(coarse) → lg 사이드바 고정 + 힌트 숨김 + 행 40px / 키보드 `t` → `activity` → ActivityPage
- 🔴 사용자: 배포 후 iPad 가로에서 4섹션·Dividends 부재·힌트 부재·오탭 없는 탭 확인
