사용자가 장애의 원인이나 맥락을 직접 알려 주면, 그 축으로만 계획·진행한다. 다른 가설을 검증하려고 클라우드 로그·프로젝트 목록 조회처럼 범위를 넓히지 않는다.

**Why:** 2026-11-10 시트 갱신 장애 진단 중, 사용자가 "KIS 시크릿(앱키·앱시크릿) 11/9 갱신했다"고 알려 줬는데도 GCP 프로젝트 목록·Cloud Logging 조회로 넓히려다 두 번 중단당함 → "그거 위주로만 진행해. 계획 보고해."

**How to apply:** 사용자 맥락 → 그 맥락의 후속 절차만 계획으로 보고하고 승인 대기([[작업 전 방향 상의 및 승인]]). 확인이 필요하면 사용자 손으로 10초면 되는 것(시트 셀 하나)을 먼저 요청한다. 내가 실측할 수 있어도 범위 밖 실측은 계획에 "선택"으로만 적는다. 관련: [[feedback_reframe_before_options]]
