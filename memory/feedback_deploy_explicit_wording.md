`push_safe.py` 실행과 웹앱 재배포는 사용자가 "진행해"·"둘 다 진행해"처럼 배포가 들어 있는 계획 전체를 승인해도 자동 승인 단계에서 거부된다 (2026-11-10 두 번, 2026-11-13 한 번). "재배포 진행해"처럼 배포를 직접 가리키는 말이 있었을 때만 통과했다.

**Why:** 배포가 포함된 계획을 승인받고도 마지막 단계에서 멈춰 사용자에게 한 번 더 물어야 했다 — 왕복 1회 낭비, 사용자는 이미 허락했다고 생각한 상태.

**How to apply:** 배포가 들어가는 계획을 보고할 때 고를 문구 자체에 배포를 넣는다 (예: "둘 다 진행하고 배포까지"). 거부되면 우회하지 말고 배포와 무관한 작업(시험·문서·커밋)을 끝낸 뒤 "배포 진행해"를 요청한다. 영구 해결은 사용자가 push_safe 허용 규칙을 설정에 넣는 것(계획서 `docs/plans/2026-11-10-KIS-키-연간갱신-대비.md` §4-G, 미결). 관련: [[feedback_just_do_it]] · [[reference_gas_redeploy_via_api]]
